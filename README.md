# Venezuela Ganadera 2030 - Flipbook Digital Interactivo

Página web interactiva estilo libro (Flipbook 3D) para el documento **Venezuela Ganadera 2030 (Master Plan Nacional para el Desarrollo Ganadero y Pecuario)**.

## Características
- Efecto realista de paso de página (StPageFlip) con físicas de papel.
- Portada real reordenada al inicio (Página 33 del PDF original) y página 34 descartada.
- Páginas en formato WebP en alta resolución (1530x1980) para lectura nítida.
- 100% Responsive: Vista de 2 páginas en pantallas grandes y 1 página en móviles.
- Controles de Zoom interactivo, Pantalla Completa, Sonido de páginas y Panel de Miniaturas.
- Atajos de teclado para navegación rápida.
- 100% compatible y optimizado para **Vercel**.

## Cómo desplegar en Vercel

### Opción 1: Conectar con GitHub (Recomendada)
1. Sube esta carpeta a un nuevo repositorio en tu cuenta de GitHub.
2. Ingresa a [vercel.com](https://vercel.com) e inicia sesión.
3. Haz clic en **"Add New..."** -> **"Project"**.
4. Selecciona tu repositorio y haz clic en **"Deploy"**.
5. ¡Listo! Tu libro estará online en segundos con certificado SSL gratis y CDN global.

### Opción 2: Usar Vercel CLI
En la terminal dentro de esta carpeta:
```bash
npm install -g vercel
vercel
```
